## Codex 委譲アドオン

Codex は**別クォータ・別モデルの実行系**であって、Claude の代替ではない。
いつ渡すか / 何を渡すか / 何を返させるかは `skills/delegating-to-codex/SKILL.md` を読む。

このアドオンは、その skill が「機械的に決めろ」と定めている部分の**実装**である。

- 委譲は `./scripts/codex/delegate.sh` を通す。**生の `codex exec` を直接叩かない。**
  status は終了コードから、`files_modified` は git から決まる。手で叩くと、
  この2つが委譲先の自己申告に戻る。
- 別モデルのレビューは `./scripts/codex/review.sh`。**自分のレビューを終えた後**に走らせる。
- **サンドボックスは read-only 固定で、上書きできない。** 書き込みを伴う委譲はしない。
- **委譲は節約ではなく移転である。** 実測で Codex は同じ作業に 3.6倍のトークンを使う。
  減るのは Claude 側の消費だけで、総量は増える。1〜2ファイルの確認は自分で読む方が安い。
- 返ってきた `claims` の `falsified` から修正タスクを作らない。**誤った前提を潰したこと
  自体が成果**であり、そこで打ち切る。
- 「テストが通った」は、自分で確認するまで通ったことにしない。`commands` の exit code
  を見るか、自分で再実行する。

停止条件:

- `codex` が PATH に無い、または未ログイン → **委譲しない。自分でやる。**
- `delegate.sh` が exit 3 を返した（read-only のはずが変更が出た）→ **止まって人間に報告する。**
  返ってきた内容を信用しない。
- 同じ委譲が3回失敗した → タスクが大きすぎる。分割するか、自分でやる。
