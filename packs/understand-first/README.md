# understand-first

この pack は、既存コードや既存仕様を理解してから変更するための補助資産であり、scaffold 時に本体テンプレへマージされる opt-in pack である。

## 何を解決するか

- 既存実装を十分に読まずに変更して壊す
- 影響範囲を把握しないまま修正する
- 用語、責務、依存関係を誤解したまま進む
- 理解した内容が chat に流れて次回再利用できない

## 基本思想

1. まず、対象領域を特定する
2. 関連する実装、docs、memory を読む
3. 責務、入出力、依存関係、リスクを言語化する
4. 未解決事項と安全に変えられる境界を残す
5. その後にだけ実装へ進む

## パック構造

- `pack-manifest.sh`
  - pack の基本情報と merge 元ディレクトリを定義する
- `merge/`
  - 新規プロジェクトへそのまま配置されるファイル
- `append/`
  - 既存ファイル末尾へ追記される断片

## 導入

新規プロジェクトには直接コピーせず、base template の scaffold から適用する。

## 使い方

1. scaffold で pack を適用する
2. `./scripts/workflows/understand-first.sh` を実行する
3. `memory/understanding-map.md` に読んだ内容と未解決事項を残す
4. 安全境界と影響範囲の仮説が書けてから実装へ進む
