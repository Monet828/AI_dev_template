## スライド作成時の共通ルール

スライド、提案資料、プレゼン、デッキ、発表資料、レポートスライドを作る場合は、最初にローカルの slide 資産を参照する。

- `assets/slides/SLIDE-md/`
- `assets/slides/SLIDE-PATTERN/`

守ること:

- 新規にスライド構成やレイアウトを発明する前に、既存の `SLIDE-md` と `SLIDE-PATTERN` を優先して再利用する。
- 余計なダウンロードや外部探索を始める前に、ローカル資産で足りるかを確認する。
- 「無難なスライド」ではなく、既存パターンを活かして、意図が明確で見栄えの良いスライドを作る。
- Claude Code / Codex どちらでも同じ方針を適用し、ツール固有の記憶ではなく、このルールを正本とする。
