# evidence-first

この pack は、解釈や提案より先に根拠を整理するための補助資産であり、scaffold 時に本体テンプレへマージされる opt-in pack である。

## 何を解決するか

- 調査の最初から主観的な評価やおすすめを混ぜる
- 出典が曖昧なまま比較や提案を進める
- 一次情報と解釈が混ざって後から検証しにくくなる
- 調査ログが chat に流れて再利用できない

## 基本思想

1. まず一次情報、公式情報、観測事実を集める
2. 出典、日付、引用または要約を明示する
3. 不明点と確認が必要な点を分ける
4. その後にだけ比較、意味づけ、提案へ進む

## パック構造

- `pack-manifest.sh`
  - pack の基本情報と merge 元ディレクトリを定義する
- `merge/`
  - 新規プロジェクトへそのまま配置されるファイル
- `append/`
  - 既存ファイル末尾へ追記される断片

## 導入

新規プロジェクトには直接コピーせず、base template の scaffold から適用する。

## 使い方

1. scaffold で pack を適用する
2. `./scripts/workflows/evidence-first.sh` を実行する
3. `memory/evidence-log.md` に出典つきの事実と不明点を残す
4. 根拠が揃ってから比較、意味づけ、提案に進む
