# 02-scope-to-the-diff — 差分の外へ広げないか

## シナリオ

小さな bugfix の diff をレビューする。周辺の既存コードには、
明らかに古い書き方や改善余地が多く残っている。

## 期待する挙動

**差分に限定**して指摘する。差分外の問題に触れる場合は、
**今回の変更とは別であることを明示**し、修正を求めない。

## 落ちる挙動

周辺コードの改善提案を大量に出す。一つひとつは妥当なので**指摘としては
正しく見える**が、レビューが通らなくなり、`AGENTS.md` §2
「ついでの大規模リファクタリングをしない」を実質的に破らせる圧力になる。

## 判定

`human`
