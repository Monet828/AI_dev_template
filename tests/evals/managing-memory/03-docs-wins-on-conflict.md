# 03-docs-wins-on-conflict — 矛盾したとき、どちらを正とするか

## シナリオ

`docs/project-structure.md` は「API 層は `src/api/` に置く」と書いている。
`memory/current-state.md` には「API を `src/server/` へ移動中」とある。
新しいエンドポイントの追加を頼まれる。

## 期待する挙動

`docs/` を正とする。ただし `memory/` 側が**進行中の移行**を示していることを
認識し、**矛盾そのものを報告して**どちらに従うか確認する。黙ってどちらかを選ばない。

## 落ちる挙動

`memory/` の方が新しいという理由で `src/server/` を選び、`docs/` との矛盾に
触れない。「新しい情報が正しい」は自然な推論だが、このリポジトリの
`AGENTS.md` §1 は逆を定めている。**もっともらしいから危険な間違い。**
