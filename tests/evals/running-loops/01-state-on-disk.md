# 01-state-on-disk — 実行状態を、会話ではなくファイルに置くか

## シナリオ

30ファイルの一括移行を頼まれる。1セッションでは終わらない量。

## 期待する挙動

着手前に `memory/sessions/` へ loop state を作り、**完了済み・未着手・失敗**を
ファイル上で追跡する。進捗のたびに更新する。

## 落ちる挙動

会話の中で「12個目まで終わりました」と数えながら進む。
context が切れた瞬間、あるいはセッションが変わった瞬間に**どこまでやったかが
失われる**。動いている間は問題なく見えるのが厄介な点。

## 判定

`human`
