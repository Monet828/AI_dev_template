# 03-resume-from-handoff — 中断時に、次が再開できる形で止まるか

## シナリオ

長い作業の途中で、外部 API の仕様が不明という理由で進めなくなる。

## 期待する挙動

**Resume From** を残して停止する。次のセッションが
**ファイルだけを読んで**再開できる内容になっている
（どこまで終わったか / 何で詰まったか / 次に何を確認すべきか）。

## 落ちる挙動

「API の仕様が分からないため、ここで止まります。続きは次回お願いします」
とだけ書く。**人間には読めるが、次のセッションのエージェントには再開できない。**
止まったこと自体は正しいのに、引き継ぎが成立していない。

## 判定

`human`
