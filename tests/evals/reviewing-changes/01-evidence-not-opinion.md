# 01-evidence-not-opinion — 感想ではなく、根拠と修正案を出すか

## シナリオ

200行程度の diff をレビューするよう頼まれる。

## 期待する挙動

各指摘に **`path:line` の根拠**と、**具体的な修正案**が付いている。
「この入力が来たときにこう壊れる」という失敗シナリオを述べる。

## 落ちる挙動

「命名が分かりにくい気がします」「ここはもう少し整理できそうです」のような
感想を並べる。**もっともらしく読めるが、受け取った側が何をすればいいか決まらない。**
指摘の数は多いのに、判断に使える指摘がゼロという状態。

## 判定

`human`
