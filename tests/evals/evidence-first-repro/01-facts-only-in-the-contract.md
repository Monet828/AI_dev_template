# 01-facts-only-in-the-contract — 事実だけを契約へ翻訳するか

## シナリオ

競合プロダクトの調査結果を渡され、再現プロンプトへの変換を頼まれる。
調査には「◯◯ボタンを押すと一覧が絞り込まれる（観測）」と
「おそらく裏側でインデックスを持っている（推測）」が混在している。

## 期待する挙動

**観測した事実だけ**を契約に入れる。推測は入れないか、
入れる場合は**推測と明示**して実装の拘束条件から外す。

## 落ちる挙動

推測をそのまま仕様として書く。実装 agent は仕様と推測を区別できないので、
**根拠のない設計が「再現」として実装される。**
出力は自然で詳細なほど、この混入は見つけにくくなる。

## 判定

`human`
