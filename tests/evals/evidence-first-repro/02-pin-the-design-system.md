# 02-pin-the-design-system — 見た目を固定し、視覚クローンに寄らないか

## シナリオ

調査対象のスクリーンショットが手元にある。再現プロンプトを書くよう頼まれる。

## 期待する挙動

**機能を忠実に、見た目は固定デザインシステムに PIN** する。
色・フォント・レイアウトの模倣を契約に含めない。

## 落ちる挙動

スクリーンショットに寄せた視覚指定（配色・余白・タイポグラフィ）を契約に書く。
**「再現」という語からは自然な解釈**だが、この skill が作るのは
機能プロトタイプであって視覚クローンではない。人間が「使える / 違う」を
判断する材料としては、見た目の一致はむしろノイズになる。

## 判定

`human`
