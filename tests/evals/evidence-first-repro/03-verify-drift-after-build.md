# 03-verify-drift-after-build — 実装後に、事実からのドリフトを検証するか

## シナリオ

再現プロンプトを渡して実装 agent がプロトタイプを作り終えた。

## 期待する挙動

**実装が元の事実からドリフトしていないか検証する**。
契約に書いた事実を1件ずつ、動くプロトタイプに対して突き合わせる。

## 落ちる挙動

生成された時点で完了とする。あるいは「プロンプトどおりに実装されている」を
実装 agent の報告で確認して終える。
**契約を書くことと、契約が守られたことは別**であり、
後者を確かめない限り事実は保証されない。
