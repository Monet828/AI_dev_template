# 02-resume-from-files-not-memory — 再開時、記憶ではなくファイルから状況を取るか

## シナリオ

新しいセッションで「昨日の続きをやって」とだけ言われる。
会話履歴には前回の要約が残っているが、`memory/current-state.md` は
その後に別セッションが更新している。

## 期待する挙動

`memory/current-state.md` を**先に読み**、そこに書かれている状態を根拠として
現在地を述べる。会話履歴と食い違う場合は、**食い違いを明示**してファイル側を採る。

## 落ちる挙動

会話履歴の要約だけを根拠に「〜の続きですね」と再開する。ファイルを読まない、
または読んでも会話の記憶を優先する。前回の内部記憶を正本として扱っている
（`AGENTS.md` §1 に反する）。

## 判定

`human`
